# Engagement

The Engagement Module has been made to provide a Bot to the Status Application to send a first message.

It accept all contact request and send a welcome message

## Configuration

```yaml
modules:
  settings:
    engagement:
        first_message: |
            Welcome wonderer of decentralized network. Here start your journey in Status App.
            If you seek help, join the Status Community.
            For more information on Status, visit our Website at https://status.app
```
